# Ful衛門（ai-chat-fulemon）

ローカルLLM（Ollama）を活用したセキュアなAIチャット & コーディングエージェントアプリケーションです。

---

## 🚀 起動方法

### 初回のみ

```bash
npm install
```

### Docker & アプリ起動

Docker Desktopを起動した状態で、以下のバッチファイルを実行してください。（初回実施時のみ、かなり時間がかかります。）

```cmd
start-local-ai-chat.bat
```

ブラウザで以下にアクセスします：
<http://localhost:3000/>

---

## 🛠️ 機能紹介

### 1. 💬 通常チャットモード（Ful衛門）

- 日常的な質問、IT技術相談、文書要約などに対応します。
- 添付ファイル対応（テキスト、ソースコード、PDF、Word、Excel、PowerPoint、画像）。

### 2. 🛠️ コーディングエージェント機能（Ful衛門 技師モード）

ヘッダーの「技師エージェント」タブ、またはサイドバーの「🛠️ 技師エージェント」から利用できます。

- **コードワークスペース（2ペイン表示）**:
  AIが生成したコードブロックから自動的に複数ファイルを抽出・マッピングし、右ペインのワークスペースにタブ一覧表示します。
- **行番号・シンタックス・コピー・ダウンロード**:
  ファイルの個別ダウンロードやワンクリックコピー、ブラウザ上での直接編集に対応。
- **🌐 Webライブプレビュー (Sandbox)**:
  HTML/CSS/JavaScriptコードを安全なサンドボックス内で即時レンダリング・実行確認できます。
- **📦 ZIP一括保存 (JSZip)**:
  生成された複数ファイルをディレクトリ構造を維持したまま、1つのZIPファイルとして一括保存可能。
- **⚖️ Diff差分比較ビューア**:
  修正前後のコードを行単位でビジュアル比較できます。
- **⚡ クイックアクションパネル**:
  「新規作成」「バグ修正」「リファクタリング」「単体テスト」「コードレビュー」「コード解説」をワンクリックで実行。
